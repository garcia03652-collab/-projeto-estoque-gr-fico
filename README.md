# Controle de Gastos - Gráfico de Despesas

## 1. Apresentação
Projeto Front-end para controle de despesas mensais com visualização em gráfico interativo. Permite cadastrar despesas e ver distribuição por categoria. Foi desenvolvido para praticar Front-end e organização de código.

## 2. Tecnologias Utilizadas
- HTML5, CSS3, JavaScript
- Chart.js para gráficos
- LocalStorage com JSON para salvar dados
- DOM para validação de formulários

## 3. Instalação e Uso
1. git clone https://github.com/garcia03652-collab/-projeto-estoque-gr-fico.git
2. Abra o arquivo html/index.html no navegador
3. Não precisa de build, projeto puro front-end

## 4. Versionamento
Uso de GitFlow: branch main (versão estável), develop (desenvolvimento) e feature/grafico-despesas (novas funcionalidades). Commits semânticos no padrão feat, fix, docs e Pull Requests para merge na main.
